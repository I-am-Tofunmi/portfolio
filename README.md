# Portfolio

Personal developer portfolio — React, Node.js, NestJS, and Tailwind CSS. Showcasing my projects, experience, and skills.

🔗 **Live Site:** [tofunmi.dev](#)

## About

I'm Omololu Tofunmi ("Panda"), a Full Stack Developer and Computer Science student at the University of Lagos. This portfolio showcases my work across frontend, backend, and supporting data/automation skills.

## Tech Stack

**Frontend:** React, Vite, Angular, Tailwind CSS, JavaScript, RxJS

**Backend:** Node.js, Express.js, NestJS, GraphQL

**Database:** PostgreSQL, SQLite

**Tooling:** Docker, Git, Vercel, Render

## Features

- Responsive, dark-mode developer portfolio
- Sections: Hero, About, Skills, Experience, Projects, Contact
- Downloadable resume/CV
- Contact form for direct inquiries
- Built with a component-based, scalable architecture

## Getting Started

Clone the repo and run it locally:

```bash
git clone https://github.com/I-am-Tofunmi/portfolio.git
cd portfolio
npm install
npm run dev
```

Then open `http://localhost:5173` (or whatever port your dev server uses) in your browser.
